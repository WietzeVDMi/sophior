Tech Stack & Setup

2.1 Shopify Thema — Dawn

Gekozen basis: Dawn (Shopify gratis open-source thema). Bewuste keuze:

Argument
Volledig open-source — Claude Code kent de codebase en kan er clean bovenop bouwen
Minimale, schone basis zonder overbodige third-party code
Gratis — geen licentiekosten voor een betaald thema
Shopify onderhoudt Dawn actief — altijd compatible met nieuwste features
Maximale controle — alles wordt precies gebouwd zoals de briefing voorschrijft

Custom bouwen bovenop Dawn:

Mega menu met afbeeldingen, category filters (pill-knoppen), product sliders, alle homepage secties, cart drawer met Rebuy integratie.

⚠ App: Installeer ook de gratis Shopify Search & Discovery app voor de category filters — werkt naadloos samen met Dawn.
